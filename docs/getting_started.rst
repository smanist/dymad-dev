Getting Started
===============

After cloning our `GitHub repository <https://github.com/apus-lab/dymad>`_

You can

- Start with the hands-on notebook tutorials in :doc:`Examples <examples>`.
- Use :doc:`Agent and CLI Workflow <agent_cli_workflow>` when you want a prompt-driven training
  workflow with a reproducible CLI handoff.
- Continue with :doc:`Examples and Scripts <examples_and_scripts>` when you want broader runnable
  coverage than the notebook gallery provides.
- Read the :doc:`Developer <developer>` guides when you need the current MCP, checkpoint, package
  layering, or feature-placement rules.
- Read the :doc:`Roadmap <roadmap>` to understand the current capabilities and future directions of DyMAD.
- Explore the :doc:`API reference <api_ref>` to understand the public classes and functions available in DyMAD.
